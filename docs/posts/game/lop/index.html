LOP

ouroboros puzzle game

Lop is hungry for apples.

Made in 96 hours for GMTK Game Jam 2025 "Loop"

This game jam was done in collaboration with @quacknoodels and @riiemi! The game is a twist on the tile based puzzle game combined with the ever growing snake with the goal of devouring your tail like an Ouroboros.

Keys and buttons and bridges.

I worked on the level design and art of the game! I was able to incorporate some usual puzzle game elements like keys and doors while also producing a nice amount of levels.
